# ホーム画面 ダッシュボードリニューアル モック

Issue #2「ホーム画面のUIをモダン・ダッシュボード志向にリニューアルする」のデザイン案。

## 成果物

| ファイル                  | 内容                                       |
| ------------------------- | ------------------------------------------ |
| `index.html`              | デスクトップ版モック（左固定サイドバー）   |
| `mobile.html`             | スマホ版モック（下部タブバー）             |
| `screenshot.png`          | デスクトップ版スクショ                     |
| `screenshot-mobile.png`   | スマホ版スクショ                           |

## デザイン方針（合意事項）

- **ナビゲーション**
  - デスクトップ: 左固定サイドバー（ロゴ + アイコン+ラベルのメニュー + 下部ログアウト）。lucide アイコン。
  - スマホ: 下部タブバー（ホーム / アカウント / 投稿一覧 / ログアウト）。
- **アカウント**: 小型カード（アバター + accountName + @username）として残す。
- **導線ボタン**: 画像アイコン（png）を廃止し shadcn `Button` + lucide アイコン（`Plus` / `List`）に。
- **KPIカード3枚**: 投稿数 / 公開中 / 下書き。色分けアイコン付き（青 / 緑 / 琥珀）で最上段に昇格。
- **最近の投稿 / 下書き**: 横2カラム、サムネ維持の行リスト、「すべて見る」リンク付き。

## 補足

- Tailwind は CDN、アイコンは lucide CDN を使用した自己完結 HTML（ビルド不要）。
- スクショは Playwright MCP 未接続のためローカル Chrome の headless で撮影。
  スマホ版は `--headless` のビューポート最小幅クランプ（約500px）回避のため 500px 幅で撮影。
- ダミーデータ。実装時の色・余白・アイコンは shadcn(new-york / neutral) のトークンに合わせる。
