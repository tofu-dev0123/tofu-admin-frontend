# mobile-nav-sidebar

モバイル版ナビゲーションを、下部タブバーから**ドロワー型サイドバー**へ変更するモック。
メニュー項目の増加（ダッシュボード / 投稿 / About / Products / アカウント）で下部タブが手狭になったため。

## 変更方針

- **下部タブバーを廃止**。上部ヘッダーの**ハンバーガーボタン**でドロワーを開閉する。
- ドロワーはデスクトップの左サイドバーと同じダーク意匠・同じグループ構成（メニュー / 公開サイト / 設定）を流用。
- 左からスライドイン。スクリム（暗幕）をタップ、または×ボタンで閉じる。
- 下部にユーザーチップ + ログアウト。

## スクリーンショット

- `screenshot-closed.png`: 通常表示（上部ヘッダーのみ、コンテンツ全面）
- `screenshot-open.png`: ドロワー展開（スクリム + 左サイドバー、現在ページをハイライト）

## 実装メモ

- 対象は `Navigation.tsx` のモバイル部分（上部ヘッダー + 下部タブ）。下部タブを削除し、ヘッダーにハンバーガー + 開閉状態を追加。
- デスクトップ（`lg` 以上）の固定サイドバーは変更なし。
- 開閉状態はクライアント state。ルート遷移時・スクリム/×押下時に閉じる。
