ボタン UI/UX 統一 — たたき台

すべてのボタンを共通 Button に集約し、カーソル・ホバー・押下・フォーカス・無効・処理中の見え方を統一する。 （下の「状態一覧」は静的表示のため各状態を固定表示。実際に触れるデモは最下部）

統一ルール（全 variant 共通）

カーソル
  • 通常: pointer
  • disabled: not-allowed
  • loading: progress
アニメーション
  • ホバー: 背景色を 1 段濃く（150ms ease-out）
  • 押下: scale(0.97) + さらに 1 段濃く（100ms）
  • フォーカス: 2px のリング（キーボード操作時のみ）
処理中（loading）
  • 先頭アイコンをスピナーに置換、文言は維持
  • クリック不可（二重送信防止）、aria-busy
  • 幅が変わらないようアイコン枠を共有

状態一覧（variant × state）

variant 通常 ホバー 押下 フォーカス disabled loading

実例: エディタヘッダー（通常 / 保存中）

保存中は押したボタンだけスピナー + 文言変更、もう一方とツールバーは disabled。

実例: 公開確認モーダルのフッター

この内容で記事を公開しますか？

現状の丸型（rounded-full）・admin-main 色の独自装飾は廃止し、共通 variant に揃える。

実例: 削除確認ダイアログ

記事「サンプル記事」を削除します。元に戻せません。

触れるデモ

ホバー・押下・Tab フォーカスを実際に確認できる。「保存」を押すと 1.5 秒 loading になる。
