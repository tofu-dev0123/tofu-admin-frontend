記事一覧 再取得 UI デザイン案

検索・ページ送り・リセット時に「前のリストを保持したまま」再取得する。
下は pending 表示（薄い進捗）の 3 案。ロジックは useTransition の isPending で駆動する想定。

表示ロジック（3状態）

cold
isPending && list.length===0
まだ何も出せない → スケルトン
warm（本案の主眼）
isPending && list.length>0
前のリストを残す + 薄い pending
empty
!isPending && list.length===0
結果ゼロ → 空文言
案A

上部インジケータ（バー） + リスト薄化

一番控えめ・実装が軽い。再取得中はリスト全体を opacity 60% + 上に細い indeterminate バー。
