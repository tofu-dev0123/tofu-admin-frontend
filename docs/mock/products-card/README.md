# Products 設定 — カード形式リニューアル案

テーブル形式が横に詰まって窮屈なため、カードグリッド形式へ変更する案。

## 画面

- `index.html` — レスポンシブなモック本体（単体で開ける）
- `screenshot.png` — デスクトップ幅（1280px）
- `screenshot-mobile.png` — モバイル幅（390px）

## 変更点（テーブル → カード）

- 1 プロダクト = 1 カード。デスクトップ・モバイルとも 1 カラムの縦積み。
- カード内に情報を縦積みし、狭い列に押し込まない: 並び順バッジ `#n` + タイトル + 下書きバッジ / 公開トグル / 説明（2 行クランプ）/ タグ / フッター（リンク・GitHub リンク / 並び替え・編集・削除）。
- `link_url` と `github_url` はフッターにアイコン付きリンクで併記。両方なければ「リンクなし」。
- 非公開カードは破線ボーダー + 淡い背景で下書きと分かるようにする。
- 末尾に「プロダクトを追加」プレースホルダカードを配置。
- モバイルは上部バー（ハンバーガー + 画面名）に切り替え、サイドバーは隠す（既存のドロワーナビ運用に合わせる）。
- 編集ドロワーには GitHub URL 入力欄（既存対応済み）を含む。

## データ構造

既存の `Product` 型を踏襲: `title` / `description` / `tags` / `link_url` / `github_url` / `published` / `sort_order`。
